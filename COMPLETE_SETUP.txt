📊 CAPTURED KEYSTROKE FEATURES
═══════════════════════════════════════════════════════════════

Real-Time Metrics:
  1. Hold Time (Dwell) - ms per key
     └─ Calculated as: keyup_time - keydown_time
  
  2. Flight Time - ms between keys
     └─ Calculated as: next_keydown - previous_keyup
  
  3. Typing Speed - keys per second
     └─ Calculated as: total_keys / elapsed_time
  
  4. Mean Hold Time
     └─ Average of all hold times
  
  5. Std Dev Hold Time
     └─ Variability in hold times
  
  6. Mean Flight Time
     └─ Average time between keystrokes
  
  7. Error Proxy (Coefficient of Variation)
     └─ Ratio: std_hold / mean_hold
     └─ Higher = More stressed/inconsistent
  
  8. Consistency Score (0-100%)
     └─ Formula: max(0, min(1, 1 - error_proxy))
     └─ Higher = More consistent
  
  9. Pause Frequency
     └─ Count of hold times > 1.5x mean

🎯 HOW THE TYPING INTERFACE WORKS
═══════════════════════════════════════════════════════════════

Step 1: Event Capture
  User types → JavaScript captures keydown/keyup events
  └─ Records timestamp for each event

Step 2: Feature Extraction
  Events → Calculate hold times, flight times
  └─ Computes 8 keystroke dynamics features

Step 3: Live Updates
  Features → Update statistics in real-time
  └─ User sees live metrics as they type

Step 4: Analysis
  User clicks → "Analyze Keystroke Pattern"
  └─ Send features to Flask API

Step 5: Prediction
  Features → Pass to ML models
  ├─ Random Forest → Prediction + confidence
  ├─ XGBoost → Prediction + confidence
  └─ Compare results

Step 6: Display Results
  Results → Show:
    • Overall stress level badge
    • Individual model predictions
    • All keystroke metrics
    • AI interpretation
    • Health recommendations
