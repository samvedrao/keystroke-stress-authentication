📊 DATABASE STRUCTURE
═══════════════════════════════════════════════════════════════════════════════

USERS TABLE:
  id (Integer, Primary Key)
  username (String, Unique)
  email (String, Unique)
  password_hash (String)
  created_at (DateTime)

TYPING_SESSIONS TABLE:
  id (Integer, Primary Key)
  user_id (Integer, Foreign Key → users.id)
  
  Features (8 keystroke dynamics):
    - mean_hold_time (Float)
    - std_hold_time (Float)
    - mean_flight_time (Float)
    - std_flight_time (Float)
    - typing_speed (Float)
    - error_proxy (Float)
    - consistency_score (Float)
    - pause_frequency (Integer)
  
  Predictions:
    - rf_prediction (Integer: 0 or 1)
    - rf_confidence (Float: 0.0 to 1.0)
    - xgb_prediction (Integer: 0 or 1)
    - xgb_confidence (Float: 0.0 to 1.0)
    - ensemble_prediction (Integer: 0 or 1)
  
  Metadata:
    - text_typed (String)
    - num_keystrokes (Integer)
    - duration_ms (Integer)
    - created_at (DateTime)

⚙️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "ModuleNotFoundError: No module named 'flask_sqlalchemy'"
Solution:
  1. Activate venv: .venv\Scripts\activate
  2. Install: pip install flask-sqlalchemy
  3. Verify: pip show flask-sqlalchemy
  4. Restart Flask: python app.py

Problem: Login leads to blank page / 404
Solution:
  1. Check /dashboard route exists in app.py
  2. Verify templates/ folder has dashboard.html
  3. Check Flask error messages in terminal
  4. Restart Flask

Problem: Can't create account
Solution:
  1. Username must be unique (try different name)
  2. Email must be unique (try different email)
  3. Password must be ≥ 6 characters
  4. Check browser console for error messages (F12)

Problem: Session not saving
Solution:
  1. Check keystroke_db.db exists in project folder
  2. Try restarting Flask
  3. If corrupted, delete keystroke_db.db (recreates on startup)
  4. Check database write permissions

Problem: Models not loading for predictions
Solution:
  1. Run: python main.py (to generate models)
  2. Verify outputs/models/ has 3 .pkl files
  3. Check terminal for model loading errors
  4. Restart Flask
