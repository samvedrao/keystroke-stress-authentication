🎯 FEATURES EXPLANATION
═══════════════════════════════════════════════════════════════════════════════

TYPING SPEED:
  What: How many keys per second you're typing
  Why: Faster isn't always better - high stress can make it inconsistent
  Good: Steady 5-8 keys/s
  Watch for: Sudden drops (might indicate stress)

CONSISTENCY SCORE:
  What: How steady your typing is (0-100%)
  Why: Stressed people type more erratically
  Good: Higher is better, ideally 70%+
  Watch for: Big swings (might indicate stress)

HOLD TIME:
  What: How long you press each key (milliseconds)
  Why: Stress can make you grip keys longer
  Good: 80-150ms is typical
  Watch for: Large increases (might indicate stress)

STRESS PREDICTION:
  What: Did the models detect stress?
  Why: Keystroke patterns reveal physiological state
  Models: Both RF and XGB give predictions
  Ensemble: Takes best of both predictions

❓ COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: Why two different models?
A: Random Forest and XGBoost learn differently. Showing both gives you
   confidence in the prediction. If they agree strongly, very reliable!

Q: What does ensemble mean?
A: Combination. If RF says "Low" with 95% confidence and XGB says "High"
   with 70% confidence, ensemble trusts RF more. Smarter voting!

Q: Why save everything?
A: Stress isn't constant. You can see patterns over time. Morning stress
   vs evening? Monday vs Friday? Build your own insights!

Q: Can I create multiple accounts?
A: Yes! Each person can register. Perfect for comparing typing patterns
   between users or testing with friends.

Q: What if models disagree?
A: Check confidence scores. Higher confidence usually means more reliable.
   Ensemble shows weighted prediction. Diversity of models is strength!

Q: Is my password secure?
A: Yes! Uses SHA256 hashing. Never stored in plain text. Safe.

Q: Can I export my data?
A: The database (keystroke_db.db) is SQLite. Can export with:
   - SQLite Studio (GUI)
   - Python sqlite3 module
   - Any SQLite tool

⚠️ IF SOMETHING DOESN'T WORK
═══════════════════════════════════════════════════════════════════════════════

Problem: "ModuleNotFoundError: flask_sqlalchemy"
  → pip install flask-sqlalchemy

Problem: Can't create account / Registration fails
  → Username must be unique (try different name)
  → Email must be unique (try different email)
  → Check browser console (F12) for errors

Problem: Login doesn't work
  → Make sure you registered first
  → Check username/password exactly
  → Try clearing browser cookies

Problem: Analysis doesn't save
  → Check keystroke_db.db exists in project folder
  → Type at least 5 characters
  → Check terminal for error messages

Problem: Models not loading
  → Run: python main.py (to generate models)
  → Check outputs/models/ folder has files
  → Restart Flask (CTRL+C then python app.py)
